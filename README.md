# STERNENRING NEXT（新基盤）　P2

ナハトとヴォルトが、ノルン広場と銀鹿亭一階を歩いて往復できる新基盤です（P1：DEV-PLAYABLE-001、P2：DEV-PAPER-001）。

- 表示は **紙の舞台**（`src/render/paper-stage.js`・素のWebGL、外部ライブラリなし）が標準です。床は寝かせた1枚、建物・家具・人物は同じ向き（カメラの正面）を向いた透過の板で、奥から手前へ並びます。板ごとに紙のふち・後ろの影・地面に倒した影が付きます。
- 右上の「表示：紙の舞台／表示：平面」ボタンで、P1 の平面表示（`flat2d`）と切りかえられます（`?render=flat2d` でも平面で開きます）。WebGL が使えない端末では自動で平面になります。
- 見た目の数値（ふち・影・奥の空気・板の向き）は `data/stage-style.json` で変えられます（すべて仮の値）。
- **今の絵は完成美術ではありません。** 紙の四角に「名前（仮）」と書いた板は素材待ちの置き場所、机・暖炉・噴水は旧版の上から見たタイルを仮に立てたものです。ドット絵（`production/claude/pixel/`）が届いたら差し替えます。
- 間取り・素材はすべて**仮**です。画面左上に「仮配置」と出ます。名前つきの紙の四角は、素材が届くまでの置き場所です。
- キャラ・地面・家具の絵は旧版の素材（`adopted-legacy`）の複製を仮に使っています。正式採用の素材ではありません。
- 保存はしません（P3 から。新キーは `sternenring-next-save-v1`、旧キーには触れません）。

- ノルンは**カルディア市内の地区ではなく、カルディア市とは別の都市**です。「ノルン＝カルディア市内の地区」という案は不採用です。

- 次のことは**まだ決まっていません**。コードやデータで決めつけません。
  - ノルンとカルディア市の正確な方角・距離・ノルンの大きさ・行政の所属、第三城壁のどの門で結ばれるか
  - エルデ森林までの方角・道のりと所要時間（本文の「王国の東端」との整合は世界設定側の課題）
  - 銀鹿亭のノルン内での場所、広場の建物の並び、銀鹿亭の正式な間取り、開始位置
- カルディア市の大都市の景観（世界設定 §36-D）は、別の都市なのでノルンへ一律に当てはめません。カルディア市のマップを作るときは、ノルンとは別の地図にします。
- 正式な間取りが決まったら、`data/maps/*.json` と `data/world.json` の差し替えだけで入れかえられます（コードの変更は不要）。

## 開始演出「飛び出す絵本」（DEV-BOOK-001）
作者の決定（2026-11-22 14:00ごろ）の流れを、起動したときの最初のマップ（ノルン広場）でだけ見せます。室内外の移動のたびには出ません。
1. 本がひらく（約0.9秒） 2. 紙の板が、奥から手前へ時間差でページから起き上がる（少し行きすぎて戻る。ナハトとヴォルトは最後） 3. カメラが本全体からナハトへ寄る（ふだんの10度・60度・追従に、つなぎ目なく戻る）。全体で約2.8秒
- 六角形の光の玉（オーブ）が舞台の上をゆっくりただよいます（演出のあとも残ります。数と濃さは `data/stage-style.json` の `orbs`、`count: 0` で出ません）
- 床のまわりの表紙（革）とページの束のふちは `book`（色は仮。`keepCover: false` で演出のあとは消えます）
- **はじめに表紙（rev4）**：本が閉じた画面に「タップしてはじめる」（PCは「クリックしてはじめる」、Enter・Space でも可）が一つ出ます。その一押しで音を有効にしてから本がひらくので、本がひらく音が絵に合います
  - 一押しは一度だけ。続けて押しても（二度押し・キーの押しっぱなし）演出はとばしません（一押しから0.35秒は省略に使わない）。方向キー・十字ボタンは表紙では効きません（十字ボタンは表紙のあいだ隠れます）
  - 音が使えない・断られた・応答がない・効果音の読込が間に合わない → 最大0.8秒待って、無音のまま本がひらきます（あとから古い音を遅れて鳴らしません）
  - 表紙のあいだにタブを離れても表紙のまま。表示を平面へ切りかえると表紙は消え、そのまま歩けます。右上の音・曲・表示のボタンは表紙の上でも押せます（先に音量を変えられます）
  - `?intro=0`・平面表示・動きを抑える設定では、演出も表紙も出ません（曲は最初の操作から）
- **演出中は歩きません。** 次のどれでもすぐ終わります：右下の「とばす」／Esc・Enter・Space／画面を触る／方向キー・十字ボタン
  - 方向でとばしたときは、その入力では歩きません（短く押しただけなら0歩）。押しつづけると、0.22秒後からそのまま歩きはじめます
  - タブを離れた・表示を切りかえた → 終わった状態になります（戻ったとき演出を待たせません）
- 見せない：`?intro=0`、端末の「動きを抑える（視差効果を減らす）」設定のとき（オーブも止まります）、平面表示のとき。必ず見せる：`?intro=1`
- 確認口：`window.STERNENRING_NEXT.intro()` で、演出の状態（phase・終わった理由 endedBy・経過秒）を読めます（読むだけ）
- **「本の世界」は見た目だけです。** 物語・世界設定には関係させません。本・板・オーブの絵はすべて仮です（美術・ドット絵待ち）

## スマホで開く（同じWi-Fi）
このサーバーは **http 専用** です（https は使いません。https で開くと「安全に接続できません」と出ます）。
1. スマホを、PCと同じ家のルーターのWi-Fiにつなぐ（ゲスト用のWi-Fiは不可。モバイルデータ通信ではつながりません）
2. PC で `START_NEXT_PHONE.cmd` をダブルクリック。黒い窓に、スマホで開くアドレスと「このPCからの確認: OK」が出ます
   - 「スマホを家のWi-Fiにつないだとき」の行のアドレス（例 `http://192.168.1.6:8132/`）を使います。`192.168.137.…` は、スマホをPCのモバイルホットスポットにつないだときだけ使います
   - 初めてのときだけ、Windows が「Node.js にネットワークへのアクセスを許可しますか」と聞くことがあります。**「プライベート ネットワーク」だけ**にチェックして許可してください
3. スマホのブラウザのアドレス欄に、**`http://` から最後の `/` まで** 自分で打って開く（検索欄・履歴・おすすめに出る https の候補は選ばない）。重さを見るときは末尾に `?perf=1`
4. 開けると黒い窓に「… から http で画面が開かれました（ほかの機器から・つながっています）」と出ます
5. 終わったら、黒い窓で Ctrl+C（開いている間は、同じWi-Fiのほかの機器からも見られます）
- `http://127.0.0.1:…` はPCの中だけのアドレスなので、スマホでは開けません。
- **家の中で試すためだけのものです。** パスワードは無く、http なので、開いている間は同じWi-Fiの機器から画面と素材が見えます。外のネットワークへ出す設定（ルーターのポート開放・トンネル）はしません。

## カメラ角度を一緒に見る（?cam=1）
作者とClaudeが画面を見ながら、紙の舞台の「見下ろす角度」と「画角」を選ぶための調整パネルです。ふだんの起動では出ません。
- 開き方：アドレスの末尾に `?cam=1`（スマホなら `http://192.168.…:8132/?cam=1`、重さも見るなら `?cam=1&perf=1`）。始めの値を決めて開くときは `?cam=1&pitch=15&fov=50`
- 右上（表示切替ボタンの下）にパネルが出ます。開いた直後は**いまのマップの値**（作者の決定 2026-11-22 13:20：床から10度・画角60度）
  - 見下ろす角度：3〜80度（0＝真横、90＝真上）。画角：10〜90度
  - 動かすと、その場で画面が変わり「試し中（マップ：…）」と出ます。「戻す」でマップの値に戻ります
  - 値はどこにも保存しません（再読み込みでマップの値に戻る）。気に入った値は、数字をチャットで伝えてください。技術担当が `data/maps/*.json` の `stage.camera` に書きます
- 一緒に見てほしい点：板（建物・人物）の重なりと奥行きが見えるか／ナハトとヴォルトが歩きやすいか（十字ボタンの操作感・行き先が見えるか）／床の見え方／スマホ縦持ちで床の手前の端が画面の中ほどに見えること（下に空きが出る）をどうするか
- 重さ：`?perf=1` の左上の数字（fps・最長ms・描画ms）。スマホでは「歩きながら10秒」と「止まって10秒」の値を見ます

### 開けないときの切り分け（上から順に）
| スマホの表示 / 黒い窓の表示 | 考えられる原因 | すること |
|---|---|---|
| スマホ「安全に接続できません」、窓に「https で開こうとした接続が来ました」 | https で開いている | アドレス欄を消して `http://` から打ち直す。履歴の https 候補を選ばない |
| スマホ「安全に接続できません」、窓に何も出ない | https のまま、別の場所（他のアドレスや古い履歴）を開いている／通信が届いていない | アドレスが黒い窓の行と同じか、`http://` か、番号 8132 かを見直す。次の行へ |
| スマホ「接続できない」「応答時間が長すぎます」、窓に何も出ない | 黒い窓が閉じている／スマホが別のWi-Fi・ゲストWi-Fi・モバイルデータ／ルーターの機器どうしの分離 | 黒い窓が開いているか。スマホのWi-Fiの名前がPCのルーターと同じか（ゲスト用でないか）。Wi-Fiを一度切って入れ直す |
| 窓の「このPCからの確認」が NG | PC側のサーバーかアドレスの問題 | 黒い窓を閉じてもう一度起動。窓の文をそのまま技術担当へ |
| 窓に「ポート 8132 は使用中です」 | もう1つ開いている | 開いている黒い窓を使うか、それを Ctrl+C で閉じてから起動し直す |
| スマホに「この接続は保護されていません」等の注意（Chrome の「常に安全な接続を使用する」が有効なとき） | http のページを開く前の確認 | 黒い窓に出たアドレス（このPCの `192.168.…:8132`）であることを確かめたときだけ「サイトに移動」。ほかのサイトでは進まない。設定全体は変えない |

してはいけないこと：ブラウザの保護設定を全部切る、ファイアウォールを止める、証明書の警告をむやみに無視する、外へ公開するトンネル（ngrok など）を使う。
